# Foxel v1.0.5 Release Note

发布日期：2026-10-17 · 版本 `1.0.5+5`

---

## 新增功能

**文件批量操作**

- 长按任意文件 / 文件夹直接进入多选并选中该项，或点工具栏右上「选择」按钮
- 多选态顶部条为「取消 / 已选择 N 项 / 全选」，条目左侧圆形勾选标记、选中项浅蓝底；此时点条目即勾选，条目「⋯」与上传按钮隐藏
- 顶部计数卡显示「X 个文件（合计体积）+ Y 个文件夹」，避免误选整个大目录
- 底部悬浮操作栏：下载 / 移动 / 复制 / 删除 / 更多
- 移动与复制进入目录选择页，**来源目录、其自身及下级均禁止作为目标**

**批量重命名**

- 五种方式：查找替换（区分大小写 / 含扩展名）、添加前后缀、序号编号（起始 / 步长 / 位数 / 位置 / 连接符）、大小写转换、修改扩展名（仅文件）
- 实时预览「原名 → 新名」，应用按钮写明「应用（N 项可用）」
- 冲突在预览阶段拦截并禁用该项：目标名已存在 / 批内重名 / 批内链式或互换 / 清洗后为空
- 逐项执行、受限并发 3；单项失败不中断整批，失败项保留选中便于重试

## 问题修复

**阻断级**

- 删除账户与切换账户此前只做了单向互斥，切换过程中删除账户会让已清掉沙箱的账户被重新写回索引（僵尸账户）；现在双向互斥，且异步校验后复查账户仍存在才写索引
- 批量移动 / 复制可以把目标目录选成来源目录自身（`dst == src`）；现已禁止
- 批量重命名漏判批内链式（A→B 且 B→C）与互换（A↔B）冲突，并发下发会撞名覆盖；现已在预览阶段拦截
- 账户被删除后，传输任务控制器仍可能发起真实传输（返回哨兵任务被当作正常任务使用）；现已改为不发起任何请求
- Windows 便携版数据文件读取失败后会把空数据写回磁盘，导致账户 / 凭证 / 下载目录配置被静默清空；读取失败后禁止写入

**一般**

- Windows 便携版写盘原先是「先删除再重命名」，中间存在数据文件不存在的空窗，进程被杀即全量丢失；改为直接重命名覆盖
- 下载失败会删除目标文件，可能销毁用户下载前就存在的同名文件；现在只清理本次新建的残缺文件
- 上传入口未捕获异常，且用 `files.single` 取值，选择器异常或无文件时无提示；已改为 try/catch 与 `files.first`
- 下载授权流程在异步等待后未校验页面是否仍挂载，可能使用已销毁的上下文
- 目录列表排序不稳定，导致批量重命名的序号在多次刷新后错位；已加入稳定排序规则
- 批量下载展开文件夹时读取失败的目录被静默忽略，任务数与实际不符；现在会计数并提示
- 批量操作在异步分片之间未校验页面挂载，切账户后仍会对旧账户发起写操作
- 删除账户前先中断在途传输任务，避免继续写入已删除账户的目录
- 下载目录兜底路径与设置页「恢复默认」的口径不一致（清除本地数据后会错位）；现已统一
- 旧版本遗留键的清理原先在串行队列之外写盘；现已纳入队列且进程内幂等
- 设置页「浏览…」选择目录返回后可能写入已释放的输入框控制器

**上一版本遗留**

- macOS 沙箱缺少出站网络权限，导致无法连接服务器
- 切换目录或返回键残留「幽灵选中」，操作栏按钮可点但静默空转
- 网络抖动被误判为「登录已失效」；现在只有 401 / 403 才标记失效
- 登录页服务器地址非法时按钮卡在「登录中」

## 破坏性变更

1. **批量重命名不再支持同一批内的链式与互换重命名**（如 A→B 同时 B→C，或 A↔B 互换）。这类操作会命中冲突检测并被拦截，请分两批执行 —— 这是为了避免并发下发时服务端撞名导致文件被覆盖。
2. **Windows 便携版的数据写入策略变更**：数据文件读取失败时，本次会话不再写入磁盘（此前会把空数据写回并清空配置）。若遇到该情况，请检查文件权限后重启应用。
3. **`FoxelApiException` 增加 `statusCode` 字段**：依赖该异常类型的调用方行为不变，但凭证判定现在只认 401 / 403。
4. **文件页长按语义变更**：长按条目现在进入多选模式并选中该项（原先为弹出单条目操作菜单）；单条目操作请使用条目右侧的「⋯」按钮。

## 已知问题

**平台相关**

1. Android：API 24–32 设备访问公共 `Download` 目录未做运行时权限申请（依赖「所有文件访问权限」或系统目录选择器）
2. Android：`MANAGE_EXTERNAL_STORAGE` 在 targetSdk 36 下存在应用商店合规风险
3. Android：全局允许明文 HTTP（`usesCleartextTraffic=true`），用于自建服务与自签证书场景
4. Android：未配置签名密钥时 release 构建回退 debug 签名（可安装、不可上架）
5. iOS / macOS：仓库未提交 `Podfile`（CI 由 Flutter 自动生成），本地开发需先执行 `flutter create --platforms=ios,macos .`
6. Linux：产物未内嵌版本元数据（打包文件名不含版本号）
7. Web：目录存在但**不是受支持平台**（`media_kit`、`camera` 无 Web 实现）
8. CI：Windows 构建任务可能因 GitHub Actions runner 上的历史残留路径而检出失败（仓库侧无非法文件名，需等待 runner 轮换或使用自托管 runner）

**功能相关**

9. 批量下载大文件夹时，传输队列暂无全局并发上限（单批按受限并发 3 执行，多批可叠加）
10. 单次批量操作上限 200 项，超出会提示分批
11. 批量重命名同一批只支持一种方式，需要叠加请再执行一次；不支持正则替换与按 EXIF 日期重命名
12. 扫码添加目前复用登录页（标题「添加账户」），尚未做独立页面
13. 账户级密码 / 生物识别锁：预留未实现
14. 「清除本地数据 / 移除账户」不会删除已下载到磁盘的文件

## 安装

| 架构 | Windows | macOS | Linux | Android | iOS |
|---|---|---|---|---|---|
| x86-64 (64 位) | ZIP | — | TAR.GZ | APK | — |
| AArch64 / ARM64 | — | ZIP | — | APK | IPA |
| ARMv7 (32 位) | — | — | — | APK | — |

- **Windows**：下载 ZIP 解压后运行 `Foxel.exe`（便携版，数据在同目录 `userdata/`）
- **macOS**：解压后拖入「应用程序」；首次打开可能需在「系统设置 > 隐私与安全性」中允许
- **Linux**：解压后运行 `Foxel`
- **Android**：下载对应架构的 APK 安装，大多数现代设备选 `arm64-v8a`
- **iOS**：IPA 为未签名版本，需通过 AltStore 等工具侧载

测试服务端：`https://demo.foxel.cc`（用户名 / 密码均为 `admin`）

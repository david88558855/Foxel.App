# Foxel 客户端 v1.0.3 正式版发布说明

发布日期：2026-10-17 · 版本：`1.0.3+4` · 面向全平台

---

## 一、变更摘要

### 新增

**文件批量操作**

- 入口：长按任意文件 / 文件夹直接进入多选并选中该项，或点工具栏右上「**选择**」按钮
- 多选态：顶部条变「取消 / 已选择 N 项 / 全选」；条目左侧圆形勾选标记、选中项浅蓝底；点条目 = 勾选，条目「⋯」与上传按钮自动隐藏
- 顶部计数卡：含 X 个文件（合计体积）+ Y 个文件夹，避免误选整个大目录
- 底部悬浮操作栏：下载 / 移动 / 复制 / 删除 / 更多
- 移动与复制进入目录选择页，**来源目录及其下级禁止作为目标**（防循环 / 自我嵌套）

**批量重命名**

- 五种方式：查找替换（区分大小写 / 含扩展名）、添加前后缀、序号编号（起始 / 步长 / 位数 / 位置 / 连接符）、大小写转换、修改扩展名（仅文件）
- **实时预览**「原名 → 新名」，应用按钮写明「应用（N 项可用）」
- 冲突在**预览阶段**拦截并禁用该项：目标名已存在 / 本批内部重名 / 清洗后为空，**不提供强制覆盖**
- 逐项执行、受限并发 3；单项失败不中断整批，失败项保留选中便于重试

### 修复（发版前全量审查）

| 级别 | 问题 |
|---|---|
| 阻断 | macOS 沙箱缺少 `com.apple.security.network.client`，应用无法连接服务器 |
| 阻断 | 便携版数据文件读取异常时会把空数据写回磁盘，导致账户 / token / 下载目录配置被静默清空 |
| 阻断 | 批量重命名时 A→B 而 B 在本批未改名会漏判冲突，执行阶段覆盖掉 B |
| 阻断 | 批量操作进行中切换目录，会对父目录下的同名条目执行删除 / 移动 / 复制 |
| 阻断 | 切换目录或按返回键残留「幽灵选中」，操作栏按钮可点但静默空转 |
| 一般 | 批量删除的「失败项保留」靠错误字符串包含路径判断，恒失效 |
| 一般 | 批量下载同名文件（不同子目录）互相覆盖 |
| 一般 | 批量复制未禁止把文件夹复制到自身及子目录 |
| 一般 | 批量下载早退路径缺少 `mounted` 校验 |
| 一般 | 批量重命名只看预览就返回也被当作成功；部分失败后重试会用已不存在的旧名 |
| 一般 | 重命名冲突检测只覆盖可见项，被搜索隐藏的同名文件会被覆盖 |
| 一般 | 登录页服务器地址非法时按钮永久卡在「登录中」 |
| 一般 | 网络抖动被误判为「登录已失效」；现在只有 401/403 才标记失效 |
| 一般 | 下载失败在磁盘留下残缺文件 |
| 一般 | 便携版临时文件固定命名，多实例启动会争用（现已带 pid） |

## 三、已知限制

**平台相关**

1. **Android**：API 24–32 设备访问公共 `Download` 目录未做运行时权限申请（依赖「所有文件访问权限」或 SAF）；建议 Android 11+ 使用系统目录选择器
2. **Android**：`MANAGE_EXTERNAL_STORAGE` 在 targetSdk 36 下存在应用商店合规风险
3. **Android**：全局允许明文 HTTP（`usesCleartextTraffic=true`），用于自建服务与自签证书场景
4. **Android**：未配置签名密钥时 release 构建回退 debug 签名（可安装、不可上架）
5. **iOS / macOS**：仓库未提交 `Podfile`（CI 由 Flutter 自动生成）；本地开发需先执行一次 `flutter create --platforms=ios,macos .`
6. **Linux**：产物未内嵌版本元数据（已在 CMake 声明，但打包文件名不含版本号）
7. **Web**：目录存在但**不是受支持平台**（`media_kit`、`camera` 无 Web 实现）

**功能相关**

8. 批量下载大文件夹时，传输队列暂无全局并发上限（单批按「受限并发 3」执行，但多个批次可叠加）
9. 单次批量操作上限 200 项（设计约定，超出会提示分批）
10. 批量重命名**同一批只支持一种方式**，需要叠加就再执行一次；不支持正则替换与按 EXIF 日期重命名
11. 扫码添加目前复用登录页（标题「添加账户」），尚未做独立页面
12. 账户级密码 / 生物识别锁：预留未实现
13. 「清除本地数据 / 移除账户」不会删除已下载到磁盘的文件

## 四、升级说明

- **v1.0.2 → v1.0.3**：数据结构与存储 key 未变更，账户、下载目录配置、传输任务均可平滑保留

- 测试服务端：`https://demo.foxel.cc`（用户名 / 密码均为 `admin`）

Foxel App 账户管理设计稿

一份统一的账户体系设计：底部导航「文件 / 任务 / 设置」，账户管理作为设置页内的独立二级页； 无账户时各平台统一停留在账户管理页空态；凭证 · 下载目录 · 传输任务 · 浏览位置 · 媒体缓存五类数据按账户隔离；文件页支持多选批量操作。

平台 Android / iOS / Windows / macOS / Linux 风格 Material 3 · #F4F7FA 底 / 20 圆角 令牌 core/theme/design_tokens.dart Windows 数据 程序目录/userdata/prefs.json

账户即沙箱

  • 凭证 / 下载目录 / 任务 / 浏览位置 / 缓存按 acc_<id> 分区
  • 全局层只存账户索引与当前指针
  • 切换账户 = 换指针 + 重建界面树

切换入口收敛

  • 底部导航第三项为「设置」
  • 账户管理是设置页内的二级页（AppBar 返回）
  • 不再有底部快速切换弹层

无账户即空态

  • 全新安装 / 删光账户 → 账户管理页空态
  • 不显示登录页、不显示底部导航
  • 各平台行为一致（含 Windows 便携版）

② 账户管理页

入口：设置页 →「账户管理」行；独立二级页，带 AppBar 返回、不带底部导航

  • 常规态当前账户卡（账户色描边 +「使用中」）+ 其他账户列表（点行即切换）+ 底部「添加账户」；右上角为「编辑」。
  • 多选态AppBar 变为「取消 / 已选择 N 项 / 删除」；列表左侧出现圆形勾选框，选中项浅蓝底；未选中时「删除」置灰。
  • 规则所有账户均可勾选（含当前账户）；当前账户行标「使用中」以便识别，「全选」勾选全部。
  • 执行批量删除后退出多选：剩余账户 ≥1 → 自动切到最近使用的账户；一个不剩 → 立即进入空态。
  • 确认对话框列明被删账户与影响范围，按钮写明数量「删除 2 项」。

③ 空态与添加账户

空态是唯一的：无论从启动进入还是从设置页进入，形态完全一致

  • 空态大标题「账户」+ 副标题「还没有账户」；居中图标 + 引导文案 + 主按钮「添加账户」/ 次按钮「扫码添加」；无返回、无底部导航。
  • 手动添加服务器地址 / 显示名称（选填）/ 账号 / 密码 →「验证并添加」；成功后立即自动切换并登录。
  • 扫码添加复用网页端二维码登录，落地为「新增账户」而不是覆盖旧会话；桌面端提供「改为手动输入」退路。
  • 失败态地址不可达 / 凭据错误分别行内提示，主按钮置灰，不产生半成品账户。

④ 编辑账户

入口：账户管理页当前账户卡「编辑账户信息」，或列表项「⋯」→ 编辑账户

  • 可改显示名称（随时可改）；服务器地址（改后必须重新验证，避免地址与凭证不匹配）。
  • 只读账号由服务端返回，本地不可改。
  • 隔离开关四项默认全开；关闭「记住浏览位置」可省内存，「独立传输队列」保证切换后任务不串账户。
  • 退出登录只清凭证，账户保留并标记失效，可重新验证；不删本地文件。
  • 移除账户删除本地沙箱（凭证 / 下载目录配置 / 任务 / 缓存），并声明服务器文件不受影响。

⑤ 设置页与下载目录

底部导航第三个 tab；账户管理入口在顶部当前账户卡内

  • 账户卡头像 / 名称 / 账号 · 服务器 /「使用中」；卡内一行「账户管理」入口（显示账户总数 + 箭头）。
  • 通用下载目录（显示当前账户路径）、存储用量（真实统计该账户下载目录大小）、关于 Foxel。
  • 当前账户清除本地数据、添加账户。
  • 下载目录弹层手输路径 + 「浏览...」（`FilePicker.getDirectoryPath()`，桌面端返回真实路径、Android 走 SAF）+「恢复默认」（回填后由「保存」生效）+ 可写校验。
  • 默认命名按账户隔离，目录名优先取显示名称（`Download/Foxel/<显示名称>/`）；未填显示名称时退回 `<账户ID>`；与既有账户重名时追加短标识；非法字符自动替换为下划线。该目录在创建账户时落定，之后改名称不会让已下载文件「搬家」。
  • 权限Android 目录不可写时弹「去授权」引导到系统「所有文件访问」设置；桌面端不触发。
  • 数据目录按账户保存（foxel_acc_<id>_download_dir），旧版全局目录会在首次升级时迁给唯一账户。

⑦ 文件批量操作

入口：长按任意条目，或工具栏右上「选择」。仅在选择模式下改变点击语义，不影响日常浏览

  • 入口两种方式：长按条目直接进入多选并选中该项；或点右上「选择」进入空选择态。空目录不显示「选择」。
  • 选择模式AppBar 变「取消 / 已选择 N 项 / 全选」；条目左侧出现圆形勾选框，选中项浅蓝底；此时点条目 = 勾选（不再打开），条目右侧的「⋯」按钮隐藏。
  • 计数顶部信息条给出「含 X 个文件（合计体积）+ Y 个文件夹（共 Z 项）」，避免误选整个大目录。
  • 操作栏底部悬浮胶囊四项主操作：下载 / 移动 / 复制 / 删除（删除为危险色），第五项「更多」展开完整菜单。
  • 更多菜单下载、移动到…、复制到…、批量重命名（后续支持，置灰）、删除、取消选择。
  • 删除确认列明数量与构成（含几个文件夹、多少内容、合计体积），声明不可撤销；按钮写明确数量。
  • 目标目录移动 / 复制进入目录选择页：面包屑 + 当前目录「移动到此文件夹」+ 子目录逐级进入；来源目录自身不可选为目标，其下级也不可选（防循环）。
  • 命名冲突同名项自动追加「(1)」后缀，不覆盖已有文件，结果以 Toast 汇总。
  • 执行反馈操作后自动退出选择模式；Toast 汇总（如「已加入 5 个下载任务」「已移动 3 项」）；失败项保留选中并提示原因，便于重试。
  • 接口下载 → 文件夹递归展开后逐个 downloadFile；移动 / 复制 → 逐项 move / copy；删除 → 逐项 deletePath（目录为递归删除）。受限并发（建议 3），避免打爆服务端。
  • 边界切换目录或搜索结果变化 → 退出选择并清空；单次上限 200 项，超出提示先分批；选择模式不跨目录累积。

各平台数据位置

  • Android / iOS：应用私有目录（卸载即清除）
  • Windows（便携版）：<程序目录>/data/shared_preferences.json —— 删除程序目录即清空，重装后回到空态
  • macOS / Linux：系统应用支持目录

数据迁移与清理

  • 只迁移一次：仅当索引不存在时才把旧会话包装成「默认账户」
  • 迁移后写入标记并清除旧键（foxel_token 等）
  • 已进入多账户体系的老设备会被幂等清理，杜绝「删光账户后重启又复活」
  • 旧版全局下载目录在清理前会迁给唯一账户，老用户的目录设置不丢

⑨ 异常与确认态

配合账户管理页使用；批量删除确认见第 ② 页、文件批量删除见第 ⑦ 页

  • 失效账户管理页顶部橙色提示条 + 列表行「失效」标记，一键重新验证；本地沙箱数据保留，不静默失败。

# Foxel v1.0.6 Release Note

发布日期：2026-10-17 · 版本 `1.0.6+6`

---

## 新增功能

**Windows 系统托盘常驻**

- 启动后即常驻托盘：进程起来、通知区域出现 Foxel 图标，主窗口**一次都不会出现**（不是"先闪一下再隐藏"），任务栏也没有程序按钮
- 托盘图标**右键**弹出系统原生菜单，严格两项：「显示主窗口」「退出」——无分隔线、无图标、无子菜单
- **左键双击**托盘图标等效「显示主窗口」，与菜单项共用同一回调（`TrayIcon::InvokeShow()` → `FlutterWindow::ShowMainWindow()`），位置、尺寸、最大化状态、任务栏按钮完全一致；左键单击不做任何事
- 点窗口关闭按钮 / `Alt+F4` / 任务栏「关闭窗口」只**收进托盘**：窗口隐藏而非销毁，正在进行的传输不中断，恢复时原样弹出
- 只有托盘菜单「退出」才真正结束进程；退出顺序为「先摘图标 → 再销毁窗口」，通知区域不留残余图标
- 资源管理器（`explorer.exe`）重启后自动重挂托盘图标（监听 `TaskbarCreated`）
- 单实例：重复双击 `Foxel.exe` 不会开出第二个实例，而是把已有主窗口唤到前台
- 首次启动弹一次通知区域提示（仅一次，标记写入 `userdata/.tray-hint-shown`；删除程序目录即恢复"首次"）

实现范围：仅 `windows/runner/`（新增 `tray_icon.{h,cpp}`、`app_messages.h`，修改 `flutter_window.{h,cpp}`、`main.cpp` 与 CMake 配置）。**Dart 业务代码与 `pubspec.yaml` 零改动**，Android / iOS / macOS / Linux 的产物与行为不受影响。设计稿见 `docs/foxel-tray-design.html`。

## 问题修复

**一般**

- Windows 便携版重复启动会同时跑起多个实例，并互相覆盖 `userdata/prefs.json`（后写覆盖前写，账户与配置可能丢失）；现在第二个实例只负责唤起已有窗口并立即退出
- 托盘图标挂载失败时会回退为直接显示主窗口，避免出现「进程在跑但看不见、点不到」的死局
- 中文菜单文案的编码：runner 目标补 `/utf-8`，避免 MSVC 按本地代码页解析导致编译失败或菜单乱码

---

## 破坏性变更

1. **Windows 启动行为变更**：不再自动显示主窗口，改为托盘常驻；首次使用需从托盘图标进入
2. **Windows 关闭行为变更**：点关闭不再退出程序，只收进托盘；需要退出时请用托盘菜单「退出」

## 已知问题

**平台相关**

1. Windows：托盘图标可能被系统收纳进「隐藏的图标」溢出区，可在任务栏设置中固定
2. Windows：首次启动的提示气泡受系统通知设置影响，关闭通知时可能看不到
3. Windows：`flutter run` 调试时窗口同样不会自动显示（与发布版行为一致），需从托盘菜单打开
4. Android：API 24–32 设备访问公共 `Download` 目录未做运行时权限申请（依赖「所有文件访问权限」或系统目录选择器）
5. Android：`MANAGE_EXTERNAL_STORAGE` 在 targetSdk 36 下存在应用商店合规风险
6. Android：全局允许明文 HTTP（`usesCleartextTraffic=true`），用于自建服务与自签证书场景
7. Android：未配置签名密钥时 release 构建回退 debug 签名（可安装、不可上架）
8. iOS / macOS：仓库未提交 `Podfile`（CI 由 Flutter 自动生成），本地开发需先执行 `flutter create --platforms=ios,macos .`
9. Linux：产物未内嵌版本元数据（打包文件名不含版本号）
10. Web：目录存在但**不是受支持平台**（`media_kit`、`camera` 无 Web 实现）

**功能相关**

11. 批量下载大文件夹时，传输队列暂无全局并发上限（单批按受限并发 3 执行，多批可叠加）
12. 单次批量操作上限 200 项，超出会提示分批
13. 批量重命名同一批只支持一种方式，需要叠加请再执行一次；不支持正则替换与按 EXIF 日期重命名
14. 扫码添加目前复用登录页（标题「添加账户」），尚未做独立页面
15. 账户级密码 / 生物识别锁：预留未实现
16. 「清除本地数据 / 移除账户」不会删除已下载到磁盘的文件

## 安装

| 架构 | Windows | macOS | Linux | Android | iOS |
|---|---|---|---|---|---|
| x86-64 (64 位) | ZIP | — | TAR.GZ | APK | — |
| AArch64 / ARM64 | — | ZIP | — | APK | IPA |
| ARMv7 (32 位) | — | — | — | APK | — |

- **Windows**：下载 ZIP 解压后运行 `Foxel.exe`（便携版，数据在同目录 `userdata/`）。**启动后不会弹窗口，请在通知区域找到 Foxel 图标**（右键「显示主窗口」或左键双击图标）
- **macOS**：解压后拖入「应用程序」；首次打开可能需在「系统设置 > 隐私与安全性」中允许
- **Linux**：解压后运行 `Foxel`
- **Android**：下载对应架构的 APK 安装，大多数现代设备选 `arm64-v8a`
- **iOS**：IPA 为未签名版本，需通过 AltStore 等工具侧载

测试服务端：`https://demo.foxel.cc`（用户名 / 密码均为 `admin`）
